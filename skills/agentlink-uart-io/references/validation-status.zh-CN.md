# 验证边界

[English](validation-status.md) | **简体中文**

文档基线：固件 0.3.2 / Control 协议 2。这是开发状态记录，不是量产认证报告。

| 项目 | 已有证据与待完成工作 |
| --- | --- |
| macOS USB / Control 帮助 | 已实物验证，包括多包长帮助、行结束符和错误恢复。 |
| Windows / Linux / USB 全速 | 尚待实物验证，不能用主机测试代替。 |
| 双 UART CDC | 已测试 115200、1 Mbaud、3 Mbaud，3 Mbaud 限定数据量并发传输一致；持续满速和长时间验证未完成。 |
| UART1 CTS | 已在 115200 实物验证暂停和恢复。 |
| UART1 RTS | 暂缓验证，不能宣称 RTS 或背压行为已经通过验证。 |
| SPI | 已通过通用 MCP 使用 Mode 0 发送数据刷新真实屏幕；其他模式和接收仍待实物验证。 |
| I2C | 实物总线验证尚未完成。 |
| ADC | 当前板子的模拟通路和测量精度仍需验证。 |

3 Mbaud 是产品目标，也是测试过的配置，不代表所有流控、持续吞吐或主机平台场景均已验证。当前未实现周期 GPIO、PWM、SPI 从机或屏幕专用固件服务。

2026-11-01：用户提供的 Claude 运行记录显示通过自行编写的 Control 串口代码完成屏幕初始化、2×5920 字节传输和刷新，用户确认显示成功。这是直接串口路线的实物证据，不是 MCP 测试。
